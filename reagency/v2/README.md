# World of Shadow Work -- v2 content spine

This directory holds the **v2** content spine -- the honesty-critical, zero-GPU text the v2 runtime
will read. It is a **separate body of work from v1** (v1 is frozen at commit `b2fb985` on branch
`world-of-shadow-work`); everything here lives on the **`v2` branch** and does not touch v1.

## Files
- **them.txt** -- the persistent THEM credit-envelope rows: the real, named-by-relation harmed
  workers AI is built on, held OUTSIDE the comfortable "we". Each row Google-able (role | place |
  wage | company/case | source + date).
- **captions.txt** -- the ME / YOU / THEM / US confession lines (hand-authored, zero-model,
  structural-fact-not-emotion), each resting on a verified noun + source.
- **lexicon.txt** -- the historical<->present labor rhyme + the contemporary AI-labor terms +
  the key nouns in the workers' OWN languages (Swahili / Spanish / Tagalog).
- **colophon.txt** -- the colophon-as-ledger (books the makers' OWN supply chain), the limit named
  aloud, the one costly-commitment template, and the program-note bibliography.

## Provenance
Every fact was web-researched and then **adversarially fact-checked**; only confirmed/corrected
facts shipped. The one unverifiable claim (a "120,000 London servants" figure) was dropped and
replaced. Individuals appear only via their OWN public organizing / on-record union testimony or as
named plaintiffs of public legal cases -- no private suffering is narrated for spectacle. The link
to the CC0 public-domain museum corpus is the **machine** (CLIP / labeling / RLHF), never a claim
that the corpus was scraped from these workers.
